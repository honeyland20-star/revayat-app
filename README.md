# روایت — اپلیکیشن اندروید ویژه هفته بسیج

روایت‌هایی استوری‌وار از زندگی شهدا و بسیجیان؛ هر روز از هفته بسیج (۲۹ آبان تا ۵ آذر) یک روایت تازه باز می‌شود.

## دانلود APK
آخرین نسخه همیشه در بخش **Releases** همین مخزن است. هر تغییری که در شاخه `main` ثبت شود، گیت‌هاب خودکار یک APK تازه می‌سازد (تب **Actions**).

## افزودن عکس‌های واقعی
عکس هر شخصیت را با نام زیر در پوشه `app/src/main/assets/photos/` آپلود کنید (jpg یا png یا webp). تا عکسی نباشد، طرح گرافیکی نمایش داده می‌شود.

| شخصیت | نام فایل |
|---|---|
| داستان یک فرمان (تاریخ بسیج) | `basij.jpg` |
| بهنام محمدی | `behnam.jpg` |
| محمدحسین فهمیده | `fahmideh.jpg` |
| مصطفی چمران | `chamran.jpg` |
| حسن باقری | `bagheri.jpg` |
| محمدابراهیم همت | `hemmat.jpg` |
| عبدالحسین برونسی | `borunsi.jpg` |
| مهدی باکری | `bakeri.jpg` |
| محسن حججی | `hojaji.jpg` |

در گیت‌هاب: وارد پوشه `app/src/main/assets/photos` شوید ← **Add file** ← **Upload files** ← **Commit changes**. چند دقیقه بعد APK جدید در Releases آماده است. عکس عمودی با عرض حدود ۱۰۸۰ پیکسل بهترین نتیجه را می‌دهد.

## ویرایش متن روایت‌ها
همه متن‌ها در فایل `app/src/main/assets/content.json` است. فیلد `day` روز باز شدن روایت در هفته بسیج است (۱ تا ۷؛ صفر یعنی همیشه باز).

## ساخت دستی
با Android Studio پروژه را باز کنید و `assembleRelease` را اجرا کنید (JDK 17، Gradle 8.9).
